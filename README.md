# Employee-Attrition-Prediction
Machine Learning project for predicting employee attrition using various ML models, SHAP explainability, and Streamlit.

# Team
This project was developed collaboratively by a three-member team as part of an academic machine learning project.

# Project Overview
The aim of this project is to predict employee attrition using machine learning algorithms. Multiple machine learning models were trained and compared. The top-performing models were further optimized using hyperparameter tuning. SHAP was used to interpret the model's predictions by identifying the most influential features. An interactive Streamlit application was developed to provide a user-friendly interface for making predictions.
